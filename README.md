### 🧭 About me

I'm an engineer who turns messy, business-critical problems into **simple, dependable systems**.
Over 18 years in IT I've worked across infrastructure, operations and software — so I think about a
system end to end: how it's designed, how it's deployed, how it fails, and how the next engineer will maintain it.

Today I focus on **Python, cloud-native automation and production-grade AI applications** —
bringing the discipline of large-scale IT to modern tooling.
